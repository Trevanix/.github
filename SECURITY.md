# Security policy

This policy applies to every repository of the Trevanix organization.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Instead, use one of these:

- GitHub's private report: the repository's **Security** tab → **Report a vulnerability**.
- Email: [security@trevanix.com](mailto:security@trevanix.com).

Include what is affected, how to reproduce it and the impact you expect. We will acknowledge the report within
7 days and keep you updated until it is fixed. Thank you for helping keep our users safe.

## Supported versions

Only the latest version on the `main` branch of each project receives security fixes.
