## How we build

- **Free and open:** MIT licensed, no accounts, no telemetry.
- **No surprise costs:** if a tool touches a paid service, it refuses anything that would charge you.
- **Works where you are:** Windows is a first-class platform, not an afterthought.
- **Tested:** every project ships with tests that run on each change.
- **AI-agent friendly:** each repo has an `AGENTS.md` so Claude Code, Codex, Gemini CLI and others can guide you.
